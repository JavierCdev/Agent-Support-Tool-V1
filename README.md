# Generador de Notas

Proyecto web estático para generar notas de interacción.

## Estructura

- `index.html`: página principal.
- `css/styles.css`: estilos.
- `js/app.js`: comportamiento y generación de notas.

## Publicar en GitHub Pages

Sube `index.html` y las carpetas `css/` y `js/` a la raíz del repositorio, conservando esta estructura. Después, activa GitHub Pages desde la configuración del repositorio y selecciona la rama y carpeta raíz.
